# AGENTS Instructions (Repo Only)

## Working Agreements
- Respond in Korean.
- Always use TDD: write a failing test, implement, then refactor.
- Create a remote branch before work and operate only on that branch.
- After opening a PR, verify auto-merge completed successfully.
- Use Conventional Commits for commit messages.

## Process
- Prefer small, reviewable changes.
- When unsure, ask for clarification before proceeding.
